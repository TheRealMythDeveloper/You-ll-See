# Flailing

A multiplayer physics game where you control a player while swinging a mace around on a rope. 
The mace, however, is **much** bigger than you. 
Can you control it, while not getting eliminated?

## How to Play
- Move around,
- Your mace will spin around you
- Use momentum to build up speed and land hits on other players.
- Eliminate your friends
- The last player standing wins.

## What this has to store
- Playing with up to 5 friends
- funny physics
- elimination based battles

## Hosting
The game runs using Node.js, Express, and Socket.IO.

## About

You'll See is a small multiplayer game project experimenting with swinging physics, momentum, and chaotic arena combat. It's designed to be simple to pick up but difficult to master.
